# API endpoint catalog

> Bootstrap required. Do not infer or list endpoints until each route contract has been inspected.

For each endpoint record:

- Method and path.
- Observable purpose.
- Public, authenticated, or administrator access.
- Ownership verification.
- Links to input type and runtime validator.
- Success status and response type.
- Expected errors.
- Side effects and idempotency.
- Requirement IDs.
- Implementation and test paths.
