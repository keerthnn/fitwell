# Operations documentation

Operations documents are runbooks for configuration, deployment, database work, and recovery. Active runbooks have **operational** authority.

- [Environments](environments.md)
- [Configuration](configuration.md)
- [Deployment runbook](deployment-runbook.md)
- [Database runbook](database-runbook.md)
- [Recovery runbook](recovery-runbook.md)

Runbooks document variable names and locations, never secret values.
