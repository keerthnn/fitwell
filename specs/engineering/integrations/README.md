# External integrations

Integration documents capture externally controlled constraints and configuration that code cannot fully reveal. They must never contain credentials, tokens, secret values, or copied vendor API schemas.

- [Firebase](firebase.md)
- [Vercel](vercel.md)
- [PostgreSQL hosting](postgresql-hosting.md)

Prefer live authoritative provider information for volatile API shapes. Document project choices, console-only state, limits, and operational constraints.
