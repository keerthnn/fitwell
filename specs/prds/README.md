# Product requirement documents

PRDs define observable FitWell behavior independently of the current stack. Active PRDs have **binding product** authority.

- [System qualities](system-qualities.md)
- [Domain PRDs](domains/README.md)
- [Product requirements template](../templates/product-requirements-template.md)

Requirements use stable IDs defined in the [authoring guide](../handbook/authoring-guide.md) and trace through SDDs, code, tests, and verification according to the [traceability guide](../handbook/traceability-guide.md).
