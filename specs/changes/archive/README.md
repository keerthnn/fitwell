# Archived changes

## Purpose

This directory preserves completed Full SDD reasoning, task history, design deviations, and verification evidence. It supports audits and future decisions but is not current product or engineering authority.

## Organization

Store packages by completion year while retaining their original directory names:

```text
archive/2026/2026-08-15-semantic-change-name/
```

- [2026 archive index](2026/README.md)

## Archive rules

- Move the complete package; do not extract selected artifacts.
- Do not alter accepted historical reasoning except to fix broken links or add a clearly dated correction.
- Current rules must be folded into PRDs, SDDs, ADRs, or runbooks before Archive.
- If an archived design is later replaced, update canonical documents and create a new change; do not rewrite history.
- Sensitive values and personal data remain prohibited.

## Discovery

Year indexes list archived package name, outcome, affected domains, verification date, and links to any ADRs created or superseded.
