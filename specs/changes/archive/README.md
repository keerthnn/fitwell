# Archived Full SDD changes

Verified Full SDD packages are stored under a four-digit year directory while retaining their original dated directory name.

Example:

```text
archive/2026/2026-08-15-semantic-change-name/
```

The archive preserves rationale and verification evidence. Current rules must live in canonical PRDs, SDDs, decisions, or runbooks.
